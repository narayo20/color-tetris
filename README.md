# 컬러 테트리스 (COLOR TETRIS)

웹 브라우저에서 실행되는 클래식 테트리스입니다. 7종 테트로미노가 각각 고유한 색상으로 표시됩니다.

| 블록 | 색상 |
| --- | --- |
| I | 시안 (`#22d3ee`) |
| O | 노랑 (`#facc15`) |
| T | 보라 (`#a78bfa`) |
| S | 초록 (`#4ade80`) |
| Z | 빨강 (`#f87171`) |
| J | 파랑 (`#60a5fa`) |
| L | 주황 (`#fb923c`) |

## 실행 방법

빌드 과정이 없습니다. `index.html`을 브라우저에서 바로 열면 됩니다.

로컬 서버를 사용하려면 이 디렉토리에서 다음을 실행하세요.

```bash
python -m http.server 8000
```

그 후 `http://localhost:8000` 에 접속합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` | 좌우 이동 |
| `↓` | 소프트 드롭 (칸당 1점) |
| `↑` / `X` | 시계 방향 회전 |
| `Z` | 반시계 방향 회전 |
| `SPACE` | 하드 드롭 (칸당 2점) |
| `C` / `SHIFT` | 블록 보관 (한 번에 한 번) |
| `P` / `ESC` | 일시정지 |
| `R` | 다시 시작 |
| `ENTER` | 시작 / 다시 시작 |

모바일에서는 화면 하단의 터치 버튼으로 조작할 수 있습니다.

## 게임 규칙

- 10 × 20 보드, 7-bag 랜덤 생성
- 줄 삭제 점수: 1줄 100점, 2줄 300점, 3줄 500점, 4줄 800점 × 레벨
- 10줄을 삭제할 때마다 레벨 상승 및 낙하 속도 증가
- 다음 블록 미리보기, 보관(HOLD), 착지 위치 미리보기(고스트) 지원
- 최고 점수는 브라우저 `localStorage`에 저장

## 파일 구조

- `index.html` — 화면 구조
- `style.css` — 스타일 및 반응형 레이아웃
- `tetris-core.js` — 보드/블록/회전/줄 삭제 등 순수 게임 로직 (브라우저·Node 공용)
- `game.js` — 렌더링, 키보드/터치 입력, 게임 흐름
- `tests/core.test.js` — 핵심 로직 테스트

## 테스트

```bash
node tests/core.test.js
```

## 참고

- 브라우저 탭을 벗어나면 자동으로 일시정지됩니다.
- 소리는 우측 상단 버튼으로 켜고 끌 수 있습니다.
